# Run 5K

A personal 8-week 5K training app for iPhone: the week's runs with pace zones,
guided warm-ups and stretches, and the steps to build each session as a custom
workout in the Apple Watch Workout app.

Live at https://rozbeh99.github.io/run5k/ (open in Safari, then Share > Add to Home Screen).

The site is served by GitHub Pages from `docs/` on `main`. Progress is saved on the device.
